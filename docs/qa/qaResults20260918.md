F-04의 관찰·증거는 보존하며 정상·해결로 판정한 것은 아니다. 현재 실행 환경은 [로컬 QA 기준](localQaBaseline20260919.md), 작업 순서는 [해결 순서](qaFixOrder20260918.md)를 따른다.

## 재현된 문제

### F-01 · P1 · 성향 검사 중 새로고침하면 응답 소실

- 관련: ONB-05, E2E-08 / 명세 1.1.2.
- 재현: 새 검사에서 첫 문항 답변 → 진행률 14% 확인 → 즉시 새로고침.
- 기대: 24시간 내 임시 답변이 있으면 이어서/새로 시작 안내, 이어서 선택 시 답변 복구.
- 실제: 진행률 0%, 첫 질문도 바뀌며 복구 안내 없음.
- 영향: 이탈·새로고침 후 검사를 처음부터 다시 해야 함.
- 확인 지점: `features/onboarding/hooks/useQuiz.ts:38`의 메모리 상태, `app/onboarding/page.tsx:35`의 질문 섞기. 이는 원인 후보이며 수정하지 않았다.
- 증거: [화면](evidence/2026-09-18/quiz-after-refresh.png), [DOM](evidence/2026-09-18/quiz-after-refresh.txt).

### F-02 · 정상으로 정정 · 직접 선택 여행 기간의 최대 5일 제한

- 관련: PLACE-01~02 / 명세 2.1.1.
- 재현: 장소 선택의 ‘그 이상’ → 시작일 2026-09-19 → 종료일 2026-09-24 이상 선택 시도.
- 확정 정책: 사용자가 최대 5일이 맞다고 확인했다. 시작일·종료일 포함 5일(4박 5일)까지 허용하며 ‘그 이상’은 4~5일이다. 기존 명세의 상한 없음 문구를 수정했다.
- 실제: 9월 24일 이후가 비활성화되어 선택 불가. 확정 정책에 맞는 동작이므로 프런트 오류에서 제외한다. API 상한 검증은 R-09 참고.
- 확인 지점: `features/places/components/TravelPeriodScreen.tsx:143`, `maxRangeDays={5}`.
- 증거: [화면](evidence/2026-09-18/custom-date-limit.png), [DOM](evidence/2026-09-18/custom-date-limit.txt).

### F-03 · P1 · 저장된 날짜가 있는 /places 새로고침에서 hydration 오류

- 재현: 당일치기 날짜를 2026-09-19로 선택 → 추천·선택 진행 → `/places` 새로고침.

### F-04 · 후순위·정책 논의 보류 · 체험 기능의 방문·완주 기록 생성

재실행 스크립트: [runProductionApiQa.mjs](runProductionApiQa.mjs). 기존 설치 의존성만 사용한다.

### 환경 차단과 수동 재테스트

- **두 사용자 UI:** 저장소를 분리하려고 `127.0.0.1:3000`을 사용했으나 운영 API가 해당 Origin에 403. 같은 공개 코스 35 GET을 무인증으로 보냈을 때 `Origin: http://localhost:3000`은 200·허용 헤더, `Origin: http://127.0.0.1:3000`은 403. [초대 오류 화면](evidence/2026-09-18/anonymous-invite.png)은 이 환경 제약이며 초대 기능 자체의 실패로 분류하지 않았다. 서로 다른 브라우저 프로필을 모두 허용된 localhost origin으로 열어 재검증한다.
- **실기기:** GPS 허용/거부, 49.9/50/50.1m 정확도, 99.9/100/100.1m 반경, 10m 이동 전파, 광주 내외, 배터리·백그라운드 복귀.
- **사진:** JPEG/PNG/WebP, 3장/4장, 10MB 경계, 메모 2,000/2,001자, 저장 실패·재시도, URL 만료, 다른 작성자 접근을 UI까지 확인.
- **추천·AI:** 1박 2일/2박 3일/장기 최소 5/7/20, 후보 소진, 유형 8/6/4/2 할당 fixture, AI 수정 2회·미리보기 거절·fallback·timeout.
- **팀·기록:** 신규/기존 계정 초대 합류, 동일 닉네임 구분, 중복 탐험 이탈, OWNER 승계 UI, 주변 장소 방문 시 코스 진행률 유지, 다른 사용자 이벤트 동기화.
- **시간·장애:** 검사 24시간 정확 경계, 공유 3일 만료·재발급, 네트워크 실패/5xx, 업로드 롤백, 요청 경합은 통제된 테스트 환경에서 실행. 운영 장애를 주입하지 않았다.
- **공유·저장:** 모바일 시스템 공유, 카카오, 이미지 다운로드, OG 미리보기는 미실행.

재테스트는 갱신된 [QA 문제 해결 순서](qaFixOrder20260918.md)를 따른다. 로컬 환경 준비 후 탐험 ID·상태 조회와 라우팅을 먼저 처리한다. F-04의 체험 기록 정책 논의·수정은 후순위로 보류하고, F-02는 정상으로 정정되어 오류 재테스트 대상에서 제외했다. 원본 계획에서 위 실행 표에 없는 세부 분기는 미실행 상태로 유지한다.
